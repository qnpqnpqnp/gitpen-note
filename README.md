# 깃펜노트

혼자 쓰는 픽셀 필기장. 서버도 설치도 없이 브라우저로 열면 바로 써.

## 실행

1. 압축을 풀어서 폴더를 원하는 곳에 둔다.
2. `index.html`을 **크롬**이나 **엣지**로 연다. (더블클릭하거나 브라우저 창에 끌어다 놓기)
3. 북마크해두면 다음부터 바로 열 수 있어.

> 동기화를 안 켜면 필기는 그 브라우저 안에만 저장돼. 폴더를 옮기거나 다른 브라우저로 열면 책장이 비어 보여.
> 그럴 땐 **설정 → 백업 파일로 저장**으로 받아둔 파일을 **백업 불러오기**로 넣으면 돼.
> 가끔 한 번씩 백업해두는 걸 추천.

## 단축키

| 화면 | 키 | 하는 일 |
|---|---|---|
| 책장 | `N` | 새 책 |
| 책장 | `/` | 책 찾기 (Enter로 첫 번째 책 펼치기) |
| 책장 | `← →` | 책 고르기, `Enter`로 펼치기 |
| 필기 | `Alt + ← →` | 쪽 넘기기 |
| 필기 | `Ctrl + Enter` | 지금 쪽 뒤에 새 쪽 |
| 필기 | `Ctrl + S` | 서명 (잠금) |
| 필기 | `Esc` 또는 `Alt + ↑` | 책장으로 (아이패드 키보드는 Esc가 없어서 `Alt + ↑`) |
| 책장 / 필기 | `M` / `Alt + M` | 소리 끄기·켜기 |
| 필기 | `Alt + B` | 도구함 열기 |
| 필기 | `Alt + Q` | 깃펜 (글쓰기) |
| 필기 | `Alt + 1~4` | 잉크병: 다홍·개나리·풀잎·바다 밑줄 |
| 필기 | `Alt + 0` | 지우개 (밑줄 지우기) |

## 도구함과 밑줄

필기 화면 위쪽 **도구함**을 누르면 칸이 펼쳐져.
- **깃펜**: 평소처럼 글쓰기
- **잉크병 4색** (다홍·개나리·풀잎·바다): 고른 뒤 글자를 드래그하면 그 색으로 밑줄. 아이패드는 손가락으로 길게 눌러 고르면 돼.
- **지우개**: 밑줄을 드래그하거나 밑줄 위를 한 번 누르면 지워져.
- 잉크병을 든 동안엔 글자가 안 써져. `Esc`나 `Alt + Q`로 깃펜으로 돌아와.
- 글을 고치면 밑줄이 그 글자를 따라 같이 움직여.
- **서명한 책에도 밑줄은 칠 수 있어.** 글은 잠겨 있고 밑줄만 추가돼서 복습할 때 표시하기 좋아.

## 게임 요소

- **잉크 경험치**: 새로 쓴 글자 1자 = 1잉크, 새 쪽 +5, 새 책 +10, 서명 +50. 차면 레벨 업.
  지웠다가 다시 쓴 글자는 안 쳐줘. 화면 오른쪽 아래에 바가 있어.
- **업적 23개**: 달성하면 오른쪽 위에 알림이 떠. **설정 → 업적 보기**로 목록 확인.
  연속 필기(3·7·30일), 아침형 인간, 벼락치기(하루 2,000자), 도서관장(서명 10권) 등이 있고,
  조건이 비밀인 **숨은 업적**도 3개 있어.
- **효과음**: 종이 넘기는 소리, 펜촉 사각 소리, 책 내려놓는 소리, 나무 도장 쿵, 탁상 종 등.
  파일 없이 코드로 합성한 소리야.
  - 상단 **스피커 버튼** 또는 `M`(필기 중엔 `Alt + M`)으로 전체 소리 끄기/켜기
  - 펜 소리만 끄려면 **설정 → 펜 사각 소리**
- **책 펼치기 연출**: 책등을 누르면 책이 빠져나와 펼쳐져.
  윈도우 설정에서 '애니메이션 효과'를 꺼두면 연출 없이 바로 열려.

## 아이패드에서 쓰기

아이패드는 파일을 직접 열 수 없어서, 앱을 인터넷 주소로 한 번 올려둬야 해. (무료)

### 1. GitHub Pages에 올리기 (처음 한 번)
1. github.com에서 오른쪽 위 **+ → New repository**. 이름은 `gitpen-note`, **Public**으로 만든다.
2. 만든 저장소에서 **uploading an existing file**을 누르고, 이 폴더 **안의 파일과 폴더 전부**를 끌어다 놓고 **Commit changes**.
3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 Save.
4. 1~2분 뒤 `https://<내 GitHub 아이디>.github.io/gitpen-note/` 로 열린다.

> 공개되는 건 앱 화면(코드)뿐이야. 필기 내용은 각 기기와 비공개 Gist에만 있어.

### 2. 아이패드 홈 화면에 추가
1. 아이패드 **사파리**로 위 주소를 연다.
2. **공유 버튼 → 홈 화면에 추가**.
3. 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 뜨고, 인터넷이 없어도 열려.

### 3. 기기 동기화 켜기 (기기마다 한 번)
1. **설정 → 기기 동기화**를 연다.
2. 안내에 있는 링크로 GitHub 토큰을 만든다. 권한은 **gist** 하나만.
3. 토큰을 붙여넣고 **연결하기**.
4. 노트북과 아이패드에서 **같은 토큰**으로 연결하면 끝. 이후엔 자동이야.
   - 고치고 3초 뒤 올림, 앱을 닫거나 다른 앱으로 넘어갈 때 올림, 열려 있으면 1분마다 받아옴
   - 같은 책을 두 기기에서 고쳤으면 **나중에 고친 쪽**이 남아. 한 책은 한 기기에서 쓰는 게 안전해.
   - 인터넷이 끊겨도 계속 쓸 수 있고, 다시 연결되면 올라가.
   - 화면 오른쪽 아래에 동기화 상태가 보여. 초록 = 맞춰짐, 노랑 = 올리는 중, 빨강 = 문제 있음.

> 토큰은 그 기기에만 저장되고 백업 파일에도 안 들어가. 토큰이 새면 GitHub의 **Settings → Developer settings → Tokens**에서 지우면 돼.

### 앱을 고친 뒤 다시 올릴 때
`sw.js` 맨 위 `VERSION`의 숫자를 하나 올리고 업로드해야 아이패드가 새 버전으로 바뀌어.

## 규칙

- 책 한 권 = 과목 하나, 최대 100쪽
- 한 쪽은 256자까지 (상단 `글자 제한`으로 끌 수 있음)
- 서명하면 그 책은 읽기 전용으로 잠김. 되돌리기 없음.
- 숫자는 `config.js`에서 바꿀 수 있어.

## 스킨 바꾸기

**설정 → 스킨**에서 고를 수 있어: 기본(나무 서재), 밤 도서관, 벚꽃, 돌 동굴, 눈 오는 오두막.
스킨은 기기마다 따로 정해져. (노트북은 밤 도서관, 아이패드는 벚꽃 이런 식으로 가능)

직접 만들려면:

화면의 색, 질감, 폰트는 전부 `skins/<스킨 이름>/` 폴더에서 불러와.

1. `skins/default` 폴더를 복사해서 이름을 바꾼다. 예: `skins/my-skin`
2. 그 안의 이미지 파일을 원하는 걸로 바꾼다. 파일 이름은 그대로 둬야 해.

   | 파일 | 쓰이는 곳 | 권장 크기 |
   |---|---|---|
   | `wall.png` | 배경 벽 | 16×16 |
   | `plank.png` | 선반, 표지판 | 16×8 |
   | `paper.png` | 종이 | 16×16 |
   | `cover.png` | 책 표지 | 16×16 |
   | `grain.png` | 책등 질감 (투명 배경) | 16×16 |

   작은 도트 이미지를 넣으면 자동으로 4배 확대돼서 픽셀이 또렷하게 보여.
3. 폰트를 바꾸려면 `.woff2` 파일을 넣고 `skin.css` 맨 위 `@font-face`의 파일 이름을 고친다.
4. 색은 `skin.css`의 `:root` 안 값을 고친다.
5. `config.js`의 `skins` 목록에 새 폴더 이름을 추가한다. 예: `skins: ['default', 'my-skin']`
6. 새로고침 → **설정 → 스킨**에서 고르면 끝.

## 파일 구성

```
index.html      화면 구조
style.css       레이아웃 (색·질감은 스킨에서)
app.js          기능 전부
sync.js         기기 동기화 (GitHub Gist)
sw.js           오프라인 지원 (인터넷 주소로 열 때만)
manifest.webmanifest, icons/   홈 화면 앱 설정과 아이콘
config.js       글자 수, 쪽 수, 스킨 목록
skins/default/  기본 스킨 (직접 만든 도트 텍스처 + 갈무리11 폰트)
```

## 라이선스 메모

기본 스킨 폰트는 갈무리(Galmuri, OFL-1.1)야. 라이선스 전문은 `skins/default/Galmuri-OFL.md`에 있어.
